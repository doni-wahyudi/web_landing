## 🚀 1. Project Identity & Tech Stack
- **Project Name**: Aurotech Landing Page
- **Mission**: A premium, high-conversion landing page for Aurotech web development services.
- **Brand Aesthetic**: Dark mode, Gold accents (`#D4AF37`), Glassmorphism, and smooth scroll reveals.
- **Tech Stack**:
  - **Framework**: React 19 (Vite)
  - **Routing**: React Router 7
  - **SEO**: React Helmet Async (Centralized in `SEO.jsx`)
  - **Styling**: Vanilla CSS (CSS Variables + Component-specific files)
  - **Icons**: React Icons
  - **Automation**: Puppeteer (Portfolio screenshot generation)
  - **Deployment**: GitHub Pages (`gh-pages`)

## 📂 2. File & Component Registry

### 🏗️ Root / Config
| File | Role |
| :--- | :--- |
| `package.json` | Dependencies, scripts (`dev`, `build`, `deploy`), and Puppeteer config. |
| `vite.config.js` | Vite build settings. |
| `index.html` | HTML template, entry point for the React app. |
| `capture_portfolio.js` | **Automation Script**: Uses Puppeteer to visit URLs in `projects.js` and save full-page screenshots to `src/assets/portfolio/`. |

### ⚛️ Source Core (`src/`)
| File | Role |
| :--- | :--- |
| `main.jsx` | React DOM initialization. |
| `App.jsx` | Main application shell. Defines Routing and wraps everything in `HelmetProvider`. |
| `index.css` | **Design System**: Contains CSS Variables (tokens), global resets, and utility classes (`btn`, `glass`, `section`, etc.). |

### 🧩 Components (`src/components/`)
Each component follows the pattern: `Name.jsx` + `Name.css`.
- **Header**: Navigation bar with "glass" effect and sticky positioning.
- **Hero**: Main landing section with CTA and glint-effect buttons.
- **Portfolio**: Grid of projects filtered by category. Integrated with `projects.js`.
- **Pricing**: Dynamic pricing cards with highlights for "Most Popular".
- **FAQ**: Accordion-style frequently asked questions.
- **Services**: Description of service offerings with iconography.
- **Preloader**: Loading screen shown on initial visit.
- **SEO**: Centralized component for managing Meta Tags, Open Graph, and Twitter Cards.
- **ScrollToTop**: Utility to reset window scroll position on route change.

### 📄 Pages (`src/pages/`)
- **Home**: Composes the landing page sections (Hero, Portfolio, Pricing, FAQ).
- **PortfolioDetail**: Dynamic route (`/portfolio/:id`) showing deep-dives into specific projects.
- **About/Terms/Privacy**: Structural content pages for legal and brand information.

### 🛠️ Hooks & Data
- **`src/hooks/useScrollReveal.js`**: Uses `IntersectionObserver` to add the `reveal-active` class to elements with `reveal-on-scroll`.
- **`src/data/projects.js`**: **The Single Source of Truth** for portfolio data. Defines project IDs, titles, URLs, and case study content.

## 🎨 3. Design Tokens & Styling
Located in `src/index.css`:
- **Primary Color**: `--primary: #D4AF37` (Gold)
- **Background**: `--bg-dark: #050505` (Carbon Black)
- **Fonts**: `Outfit` (Headings), `Inter` (Body).
- **Glassmorphism**: `.glass` class uses `backdrop-filter: blur(16px)` and semi-transparent borders.
- **Animations**: `fadeInUp` and `glint` (shimmer effect for buttons).

---

## 🔄 4. Business Logic & Data flow
1. **Routing**: Handled by `App.jsx`. Uses `BrowserRouter` (standard) with dynamic matching for portfolio details.
2. **SEO**: Every page component includes the `<SEO />` component at the top, passing custom titles and descriptions.
3. **Portfolio Screenshots**: 
   - Add a new site to `capture_portfolio.js`.
   - Run `node capture_portfolio.js`.
   - The script saves PNGs which are then imported/used in `src/data/projects.js`.
4. **Scroll Reveal**: Elements with `reveal-on-scroll` automatically animate in as the user scrolls, controlled by `useScrollReveal` hook.

---

## 📦 5. Deployment Workflow
1. **Local Development**: `npm run dev`
2. **Portfolio Capture**: `node capture_portfolio.js` (Updates assets)
3. **Build**: `npm run build`
4. **Deploy**: `npm run deploy` (Publishes the `dist` folder to the `gh-pages` branch).
